### Featured project

**[Sound Event Detection — MLPC 2026](https://github.com/volodymyrhalian/sound-event-detection-mlpc)**

Multi-label detection of 15 household sound-event classes. The project explores dataset quality, acoustic features, neural-network architectures, temporal post-processing, and transfer learning.

| Approach | Segment-based Macro-F1 (reported) |
| --- | ---: |
| Decision Tree baseline | 0.3170 |
| Feed-forward neural network | 0.4175 |
| Convolutional recurrent neural network | 0.6000 |
| Fine-tuned BEATs Strong | **0.6420** |

*Results above are taken from the university project report, not independently reproduced. Some missing project components were reconstructed and are identified in the repository.*
